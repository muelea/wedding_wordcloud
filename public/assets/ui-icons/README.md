# Configurator action icons

The inline SVG symbols in `views/partials/editor-symbols.ejs` are a curated
subset of [Lucide 1.39.0](https://github.com/lucide-icons/lucide/tree/1.39.0/icons).
Symbol ids retain the upstream icon names. Geometry is unchanged; the shared
`.editor-icon` rule supplies stroke, colour and size. Both upstream ISC and
Feather-derived MIT notices are retained in LICENSE.txt. No CDN or runtime
icon dependency is required.
