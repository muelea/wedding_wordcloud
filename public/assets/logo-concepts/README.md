# Wolkenworte logo concepts

These transparent PNG concepts were generated with the built-in image-generation
tool. They are visual directions, not yet production SVG artwork. Once a
direction is selected, redraw and optically refine it as vector paths before
shipping it as the primary brand mark.

## 01 — Gathered words

`01-gathered-words.png`

> Use case: logo-brand. Asset type: production-ready application logo concept,
> horizontal lockup. Primary request: create an original flat vector-style logo
> for the German wedding word-cloud application "Wolkenworte". The icon is a
> compact heart silhouette assembled from exactly 7 simple pill-shaped word bars
> of varied lengths, suggesting a word cloud gathering into love. Pair it with
> the exact wordmark on the right. Style/medium: strict flat vector graphic,
> clean Bezier-style geometry, minimal premium European editorial design.
> Composition/framing: one centered horizontal lockup, compact icon left,
> wordmark right, generous transparent margin, strong small-size silhouette.
> Color palette: solid deep burgundy #400F26 for wordmark and most bars, solid
> berry #9C1C4C for two bars, solid champagne #C1922F for one small bar. Text
> (verbatim): "Wolkenworte". Typography: elegant high-contrast serif, upright,
> precise kerning, not handwritten. Background: genuinely transparent alpha.
> Hard constraints: render the brand name exactly once with exact spelling; only
> fully opaque flat solid shapes and fully transparent pixels; absolutely no
> glow, blur, lighting, transparency within the mark, gradients, shadows,
> texture, outline, mockup, presentation board, extra text, tagline, or
> watermark; maximum 3 colors; icon readable at 24px. Avoid: speech bubbles,
> circles, floating particles, literal fluffy cloud, wedding rings, script
> fonts, ornament.
